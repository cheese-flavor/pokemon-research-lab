## 문서 건수 해석

| 종류 | 항목별 문서 레코드 |
|---|---:|
| 종별·버전별 도감 설명 | 20,314 |
| 관련 특성의 언어·버전 그룹별 설명 | 42,678 |
| 항목과 연결된 진화 체인 | 1,025 |
| 합계 | 64,017 |

언어별 건수는 영어 43,479 / 한국어 19,513 / 언어 미지정 구조화 진화 조건 1,025다. **64,017개의 독립된 외부 출처를 확보했다는 뜻이 아니다.** 같은 특성 설명이나 진화 체인이 여러 포켓몬 항목에 연결된 레코드와 버전별 반복 문구를 포함한다. 설명문 원문 URL은 도감·특성·진화 CSV 3종이며, 진화 문서는 종 연결 등의 보조 CSV 출처도 저장한다. 색인 전 청킹 수는 아직 측정하지 않았다.

## 캐시·재현 검증

- `python scripts/collect_pokemon_bulk.py --offline` 성공.
- 오프라인 실행에서 네트워크 요청 **0회**, 고정 원본 파일 20개 재사용.
- 다시 재생성한 `items.json`·`documents.json`의 SHA-256이 실행 전과 각각 일치.
- 문서의 언어·버전·항목 ID를 보존하여 재실행 후 문서 ID와 건수가 동일.
- 원본 캐시 SHA-256 검사 및 누락 시 실패 동작 구현. 전체 수집 실행에서 정규화 데이터 계약 검사를 수행.

## 자동 테스트

`python -m unittest discover -s tests -p test_pokemon_collection.py -v`

6개 통과:

1. 항목별 자기 설명문이 없으면 검증 실패.
2. 같은 내용이어도 항목·버전이 다르면 문서 ID가 다름.
3. 진화의 여러 분기와 아이템/레벨 조건을 보존.
4. API 캐시를 네트워크 없이 재사용하고 누락은 실패.
5. bulk 캐시를 해시 검사 후 네트워크 없이 재사용.
6. 해시가 다른 손상된 bulk 캐시는 실패.

## Git·키 관리

- `dataset/pokemon/`의 정규화 파일·원본·manifest는 모두 Git 제외 대상.
- PDF, `.env`, 벡터 DB 등 제외 규칙 유지. GitLab에는 수집 코드, 테스트, 출처/집계 결과 문서만 반영.
- 사용자 키가 `streamlit_lab/.env.example`에 들어 있음을 확인하여 `streamlit_lab/.env`로 이동하고 양식의 키 값을 비움. 키 값은 출력하지 않았고 실제 `.env`가 Git 제외되는지 확인.
- `GMS_KEY` 설정 유무만 확인했다. 인증·모델 사용 가능 여부는 검증하지 않았다.
- 사용자 지정 답변 모델: `gpt-6.1-sol`. GMS Responses 주소 및 임베딩 연결은 작업 3에서 검증한다.
