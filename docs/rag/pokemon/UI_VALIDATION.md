# 작업 6: 화면·조건 탐색·진화 카드

실행일: 2026-10-23. 기존 `step7_skeleton.py`의 항목 선택·채팅·진행·인용 구조를 발전시켜 `streamlit_lab/app.py`에 실제 서비스를 연결했다. 기존 실습 파일과 이전 ML 결과는 수정하지 않았다. Streamlit 1.62.0을 사용하며 별도 프론트엔드 심화(F2013) 구현으로 주장하지 않는다.

## 실행

프로젝트 루트 PowerShell에서 실행한다. Python 3.11 이상, 로컬 데이터·메타 색인, 무시된 `streamlit_lab/.env`의 키가 필요하다.

```powershell
streamlit_lab/.venv/Scripts/python.exe -m pip install -r requirements-pokemon-rag.txt
streamlit_lab/.venv/Scripts/python.exe -m streamlit run streamlit_lab/app.py --server.address 127.0.0.1
```

기본 주소는 `http://127.0.0.1:8501`이다. 로컬 컴퓨터에서만 접근하도록 바인딩하며 외부 배포하지 않았다. 실행 중단은 실행 터미널에서 Ctrl+C다. 데이터와 색인을 준비하는 방법은 [데이터 준비](DATA.md), [메타 색인](INDEXING.md)을 따른다. 현재 메타 1,025건과 활성 설명 224청크를 유지했다. 설명은 질문에 따라 증분 준비한다.

## 기능

| 요구사항 | 구현 | 확인 범위 |
|---|---|---|
| F2002·F2008 표시 연결 | 사이드바의 실제 색인 건수, 실제 인용한 근거의 제목/원문/유형/언어/버전/번역 표시 | AppTest와 실제 브라우저 |
| F2009 | 1,025종 선택, 항목별 채팅 기록, 선택 항목의 대화만 초기화 | 실제 캐시 답변·A→B→A 전환·근거 복원 |
| F2010 | 검색 근거에 연결된 진화 조건 카드 | 피카츄 3조건 행, 원문 링크·종 이름 출처·형태 ID·게임 범위 |
| F2011 | 자연어 조건 구조화, 의미 검색 순위, 전체 항목 속성 검사, 결과 카드에서 대화로 이동 | 4종류 자연어 입력·실제 브라우저 선택 이동 |
| F2012 | 검색어/자료 검색/선별/색인/검색/생성 단계 상태, 키·색인·결과 없음·실패 안내 | 상태 콜백·오류 상태·실제 환경과 격리된 누락 설정 |

화면은 대화·조건 탐색·진화 조건 메뉴로 구성한다. 타입은 별도 줄에 두어 좁은 화면에서도 복합 타입을 잘라 표시하지 않으며, 키·몸무게·종족값 합계는 세 개 요약 칸으로 표시한다. 질문 예시는 현재 선택 항목에 맞춰 바뀐다.

대화 기록은 포켓몬 ID별 Streamlit 세션에 저장한다. 이전 답변의 실제 인용 목록도 함께 저장해 다시 그릴 때 유지한다. 기록은 현재 브라우저 세션용이며 영구 대화 저장소가 아니다. 이전 대화 전체를 LLM의 사실 근거로 주입하지 않는다. 독립적으로 이해할 수 있는 구체적인 질문을 사용해야 하며, 복잡한 대명사·대화 문맥 해소는 미검증이다.

## 자연어 조건 탐색

GMS `gpt-6.1-sol`이 허용된 필드/연산자만 갖는 JSON으로 조건을 반환한다. 최초 등장 세대·타입·이름 일부·키/몸무게·여섯 능력치·합계·전설/환상 여부를 지원한다. 키는 m, 몸무게는 kg로 변환한다. 타입 AND/OR를 구분한다.

숫자와 불리언, 세대 범위, 유한값, 필드·연산자를 코드에서 검증한다. 임의 코드/SQL을 생성·실행하지 않는다. 메타 컬렉션 의미 검색은 순위에 사용하고, 전체 1,025종을 객관 조건으로 검사해 의미 검색에서 빠진 정확한 일치를 보완한다. 화면에 제시하는 결과는 모든 조건을 다시 통과해야 한다. 결과가 많으면 첫 12종을 표시하고 조건을 좁히도록 안내한다.

지원할 수 없는 주관적 조건이나 모호함이 있으면 그 조건을 임의로 버리지 않고 결과 제시를 보류한다. 모든 자연어 표현의 해석 정확성을 보장하지는 않는다. 화면에 해석된 조건을 보여 사용자가 확인할 수 있게 했다.

| 실제 입력 | 결과 |
|---|---|
| 1세대 전기 타입 중 몸무게 10kg 이하 | 2종. 실제 타입·세대·kg 조건 일치 확인 |
| 키 50cm 이하이고 몸무게 1000g 이하인 포켓몬 | 0.5m·1kg로 변환, 37종. 모든 표시 후보의 수치 검사 |
| 귀엽고 대전에서 무조건 이기는 포켓몬 | 미지원 조건 2개, 결과 0건. 조건을 객관적 사실로 바꾸지 않음 |
| 1세대 드래곤 타입 중 몸무게 0.1kg 이하 | 조건은 지원하지만 일치 항목 0건, 결과 없음 안내 |

4사례 모두 오프라인 재실행에서 조건/항목 목록이 동일하고 추가 모델·임베딩 호출은 0회였다. 개발 중 GMS 일시 서버 오류가 한 번 발생해 검증을 중단했고 재시도 후 완료했다. 키나 모델을 바꾸거나 오류를 빈 검색 결과로 처리하지 않았다.

## 진화 조건 카드

선택 항목의 질문별 자료를 준비한 뒤 기존 Retriever로 진화 체인 청크를 검색한다. 검색된 청크의 doc_id와 조건 행 포인터를 이용해 **동일한 원문 조건 행 전체**를 읽는다. 부분 조각만으로 전체 조건을 추측하는 방식이 아니다. 같은 행의 여러 조각은 카드 하나로 합치고 서로 다른 조건 행은 별도로 유지한다.

- 출발/도착 이름은 고정 종 메타데이터를 통해 한국어로 표시하고 종 이름 CSV 출처를 별도 연결한다.
- 행 내부 조건은 AND, 다른 행은 OR로 안내한다. 0인 요구 플래그는 요구하지 않는 항목으로 생략하되 공격/방어 관계 값 0처럼 의미 있는 수치 0은 보존한다.
- 조건 ID·기록된 버전 그룹·필수/결과 형태 ID·원문 식별자를 표시한다. 한국어 아이템 이름이 없으면 임의로 보충하지 않는다.
- 각 카드에 실제 검색 근거 번호와 조건 원문 URL을 붙인다. 검색된 일부 조건이며 전체 분기 목록이나 특정 게임의 완전한 가능성을 보장하지 않는다고 안내한다.

피카츄 사례에서 피츄→피카츄 조건과 서로 다른 결과 형태를 가진 피카츄→라이츄 조건을 합쳐 **3개 카드**로 확인했다. 카드가 없더라도 포켓몬에 진화가 없다는 사실로 단정하지 않는다.

## 오류와 비공개 정보

키 누락은 설정 안내와 입력 비활성화로 처리한다. 항목 색인이 없으면 색인 실행 안내를 표시한다. 설명 색인이 아직 없으면 첫 질문에서 자료를 준비한다고 안내한다. 손상/읽기 실패와 정상적인 결과 없음은 구분한다.

일반 오류는 사용자용 안내와 무작위 확인 번호만 표시한다. 로컬 오류 로그에도 예외 종류·작업·확인 번호만 남기고 키/예외 원문/프롬프트/스택 추적은 저장하지 않는다. 새 탐색이나 카드 준비가 실패하면 이전 결과를 새 결과처럼 보여주지 않는다.

누락 검증은 실제 키 파일을 삭제하지 않고 테스트에서 키 읽기 결과를 비운 환경으로 실행했다. 색인 누락은 별도의 존재하지 않는 manifest 경로를 지정해 실행했다. 의도적인 백엔드 예외에 비밀값처럼 보이는 센티널을 넣어도 화면·로그에 노출되지 않음을 검사했다.

## 검증과 산출물

```powershell
streamlit_lab/.venv/Scripts/python.exe scripts/verify_pokemon_ui.py
streamlit_lab/.venv/Scripts/python.exe -m unittest discover -s tests -p "test_pokemon*.py" -v
streamlit_lab/.venv/Scripts/python.exe -m pip check
```

관련 테스트 **59개**와 의존성 검사를 통과했다. 새 테스트 12개는 조건 검사·잘못된 수치/필드·주관 조건·세션 분리·로그 비노출·진화 행 확장과 Streamlit AppTest의 실제 캐시 답변, 근거 복원, 선택 이동, 진행 상태, 누락 설정, 빈 결과, 실제 진화 표 표시를 확인한다. 로컬 데이터/색인이 필요한 화면 테스트는 해당 파일이 없는 환경에서 건너뛰며, 이번 로컬 실행에서는 모두 실행했다.

실제 로컬 브라우저에서도 조건 입력→2종 표시→카드 선택→해당 항목 대화 이동과 진화 카드 출처 링크 표시를 확인했다. 좁은 809px 브라우저 화면에서 요약 정보·타입·입력창을 점검했다. 브라우저 미리보기 PNG는 `outputs/pokemon/ui/evolution-preview.png`에만 저장했다. 원본 데이터 세 파일의 실행 전후 해시가 유지됐다.

`dataset/pokemon/explore/cache/`의 모델 캐시, `outputs/pokemon/ui/`의 결과·로그·미리보기, 원본/벡터/키는 모두 Git 제외다. 이번 Git 반영은 코드·설정·테스트·집계 보고서만 포함한다. 전체 기능 제출 체크리스트, 독립된 품질 평가, 실제 교육생 상호 검증은 작업 7에서 별도로 수행한다.
