# 포켓몬 리서치 랩 요구사항 정의

설계일: 2026-10-22. 작업 2 산출물이다. 설계 확정을 구현·검증 완료로 표시하지 않는다. 로컬 프로젝트 명세서의 기능 번호를 대조해 포켓몬 도메인에 적용했다. 원문 PDF는 Git에 포함하지 않는다.

## 목적과 범위

사용자가 포켓몬을 선택하고 도감 설명·특성·진화 조건을 질문하면, 관련 문서에서 근거를 검색해 한국어로 답하고 실제 사용한 출처를 보여준다. 자연어 조건으로 항목을 탐색하고 선택한 항목의 대화로 이동한다.

- 항목: 전국도감 1~1,025번, 종마다 기본 개체 1개. 리전폼·메가진화 등은 별도 지원 대상이 아니다.
- 데이터 조건: 1,025개 항목과 64,264개 연결 문서를 확보했다. 한국어 도감 설명은 원본 898종 + 생성 번역 127종이며 번역은 공식 한국어 문구로 표시하지 않는다.
- 출처: 고정 커밋의 PokéAPI CSV. 상세 이용 조건과 재현법은 [DATA.md](DATA.md), 실제 집계는 [EDA.md](EDA.md)를 따른다.
- 지원: 현재 스냅샷의 메타데이터, 수집된 버전의 도감·특성 설명, 수집된 진화 체인 조건.
- 제외: 실시간 대전 순위, 기술 습득표, 출현 위치, 모든 형태 비교, 게임별 진화 가능성의 완전한 보장. 근거 없는 질문에는 확인 불가를 안내한다.
- 포켓몬 지식 서비스이므로 건강·금융 면책 문구는 적용하지 않는다. 생성 번역·스냅샷·버전 범위 안내는 제공한다.

## 필수 기능과 인수 기준

## 심화 기능의 경계

F2013(직접 프론트엔드), F2014(MMR), F2015(RAG 전후 비교), F2016(서로 다른 종류의 출처 결합)은 이번에 구현 범위로 선택하지 않았다. 추후 별도 작업으로 선택한다. 기본 검색의 정확한 중복 제거를 MMR 구현이라고 부르지 않으며, 동일 PokéAPI의 여러 CSV나 번역을 여러 종류의 출처 결합으로 세지 않는다.

## 화면과 사용자 흐름

1. 사이드바: 포켓몬 이름/번호 선택, 현재 메타·문서 색인 건수, 대화 초기화.
2. 조건 탐색: 자연어 입력 → 해석한 조건 표시 → 일치 카드 → 선택한 포켓몬 대화로 이동.
3. 채팅: 선택 항목·선택 게임 버전(선택 사항) 표시, 항목별 대화 보존.
4. 답변: 주요 주장 뒤 `[근거 N]`, 아래에 실제 인용한 제목·출처 유형·버전·언어·원문 링크만 표시.
5. 진화 조건 카드: 체인의 분기와 조건을 출처와 표시. 특정 게임 지원 여부가 확인되지 않으면 그 범위를 명시.
6. 진행 상태: 검색어 해석 → 출처 후보 검색 → 문서 선별/캐시 확인 → 청킹·색인 → 근거 검색 → 답변 생성.

키 없음은 “GMS 키 설정을 확인해 주세요”, 메타 색인 없음은 “항목 색인이 필요합니다”, 근거 없음은 “수집한 문서에서 확인되지 않습니다”로 안내한다. 후보 선별 실패나 외부 호출 실패를 검색 결과 없음으로 위장하지 않는다.

## 대표 질문과 검증 계획

아래는 질문·판정 기준이며 모델 답변을 실행한 결과나 정답 본문 복제가 아니다. 작업 4에서 로컬 원문 doc_id/필요 구간을 정답 자료로 고정하고, 자료는 Git 제외 경로에 보관한다.

| 사례 | 선택 항목과 질문 | 기대하는 처리·검증 |
|---|---|---|
| Q01 | 피카츄: 라이츄로 진화하는 조건은? | 연결 진화 체인에서 해당 간선 조건만 설명하고 인용 |
| Q02 | 이브이: 진화 분기별 조건을 비교해 줘 | 분기 조건 누락/혼합 검사, 특정 게임 전체 가능 목록으로 단정하지 않음 |
| Q03 | 파이리: 수집된 한국어 도감에서 꼬리 불꽃을 어떻게 설명해? | 실제 선택된 버전의 도감 설명과 인용 일치 |
| Q04 | 피카츄: 서로 다른 두 게임 버전의 설명을 비교해 줘 | 먼저 보유 버전 확인, 버전별 근거 분리. 동일 문구면 동일하다고 설명 |
| Q05 | 나옹: 특성 설명을 알려 줘 | 기본 개체 연결 특성과 해당 버전 그룹 설명 대조 |
| Q06 | 미라이돈: 바이올렛 도감 내용을 한국어로 설명해 줘 | 해당 버전 자료 확인, 생성 한국어이면 생성 번역임을 표시하고 영어 원문 연결 |
| Q07 | 피카츄: 특정 게임에서 기술을 배우는 모든 레벨은? | 미수집 범위로 확인 불가 응답, 메타데이터만으로 답을 생성하지 않음 |
| Q08 | 피카츄 선택 후: 리자몽의 설명을 알려 줘 | 항목 불일치 안내 및 선택 변경 유도, 다른 항목으로 몰래 검색 범위 변경 금지 |
| Q09 | 조건 탐색: 1세대 전기 타입 중 몸무게 10kg 이하 | 세대·타입·kg 조건을 코드로 검사, 일치 항목만 반환 |
| Q10 | 조건 탐색: 귀엽고 대전에서 무조건 이기는 포켓몬 | 주관 조건/지원 불가 조건을 명시, 객관적 조건 충족으로 단정하지 않음 |

검증은 인용 유효성, 원문 지지 여부, 항목 격리, 버전 일치, 번역 표시, 조건 정확성, 미지원 응답을 따로 판정한다. 구현 후 셀프 체크와 실제 교육생의 상호 체크를 구분하며, 상호 검증을 자동 생성하지 않는다.

## 이번 작업의 완료선

요구사항 표·데이터 경계·대표 질문·파이프라인 설계가 작성되면 작업 2를 완료한다. 다음 작업 3은 GMS 임베딩 모델/차원 확인과 메타데이터 색인이다. 현재 번역용 Responses 연결 성공을 임베딩 연결 성공으로 취급하지 않는다.
