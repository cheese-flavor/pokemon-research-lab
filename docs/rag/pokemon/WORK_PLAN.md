# 포켓몬 RAG 프로젝트: 작업 단위 및 GitLab 반영 계획

2026-10-22 사용자 결정: 반려식물 대신 **포켓몬**으로 진행한다. 전체를 한 번에 구현하지 않고 작업별로 진행·커밋·푸시한다. 이번 문서는 계획이며 데이터 확보·구현 완료를 의미하지 않는다.

## 서비스 방향

가칭 **포켓몬 리서치 랩**, 포켓몬 백과형 RAG 서비스(Streamlit 웹 앱). 포켓몬을 선택하면 도감 설명, 진화 조건, 특성 등의 문서를 근거로 질문에 답하고 인용 출처를 보여준다. 사용자 요청으로 항목 범위를 **전국도감 1~1,025번 전체 종**으로 확장했다. 종마다 기본 개체를 연결하며 형태별 개체 ID와 종 ID는 구분한다.

데이터는 PokéAPI의 종·개체 메타데이터와 도감·진화·특성 설명을 연결한다. API 인증은 필요 없으며, 캐시 및 호출 빈도 절제를 준수한다. 문서: https://pokeapi.co/docs/v2

중요한 범위: 도감 설명은 언어·게임 버전을 보존한다. 진화 체인 데이터가 모든 게임별 예외를 완전하게 표현한다고 가정하지 않는다. 버전 근거가 없는 경우 특정 버전에서 가능하다고 단정하지 않는다. 수치 상성·조건 일치 등 계산은 코드에서 처리하고 설명·근거 결합에 RAG를 쓴다.

## GitLab 관리

- 확인된 원격: `origin`, https://lab.ssafy.com/s16/b06/aicorepjt02/shin-02-ai-pjt.git
- 현재 브랜치: `main`. 브랜치 변경 지시 전에는 기존 흐름을 유지하며 강제 푸시하지 않는다.
- 작업별 검증 → 대상 파일만 스테이징 → 변경 내용·제외 규칙 점검 → 커밋 → 푸시 → 결과 보고.
- PDF, 데이터, 캐시, Chroma 저장소, 임베딩, `.env`를 올리지 않는다. 재현 가능한 수집 스크립트와 출처 문서를 올린다.
- 기존 ML 결과물 중 이미 추적된 CSV/JSON 등은 과거 작업 산출물이다. 이번 변경에서 삭제하거나 과거 이력을 재작성하지 않는다. 새 ignore 패턴은 추적된 파일을 자동으로 해제하지 않으므로 변경 시 별도 점검한다.
- 현재의 영화 데이터·국가유산 파일럿·실습 폴더는 이번 커밋에 포함하지 않는다.

## GMS 키 전달 시점 및 방식

작업 3에서 키 사용을 안내한 뒤 로컬 `streamlit_lab/.env`의 키로 임베딩을 실행했다. 루트 `.env.example`은 빈 키 템플릿이다. `.env`는 Git에서 제외된다. 번역용 Responses와 임베딩 인증·모델·차원을 실제 확인했다.

사용자 선택 답변 모델은 `gpt-6.1-sol`, GMS Responses 주소는 `https://gms.ssafy.io/gmsapi/api.openai.com/v1/responses`다. 임베딩은 GMS의 `text-embedding-3-small` 1,536차원을 실제 확인했다. 모델 목록 조회는 500으로 실패해 임베딩 실호출로 지원을 검증했다.

LLM과 임베딩 모두 GMS에서 사용 가능한 모델·주소를 실제로 확인해 설정한다. 키를 검사할 때는 설정 유무만 확인하고, 값·일부 문자열·길이·응답 헤더 등을 로그에 남기지 않는다. 키가 없으면 연결·임베딩·답변 생성 검증을 미완료로 기록한다.
