# 한국어 도감 설명 결측 원인과 분포

2026-10-22, 사용자 요청에 따른 작업 1 후속 데이터 감사. 요구사항 설계·GMS 호출·번역·원본 변경은 수행하지 않았다.

## 원인 확인

고정 원본 커밋 `2bf639e5572812a67d2b94903fdcb9d095f5aeb2`의 `pokemon_species_flavor_text.csv` 전체 언어 행과 로컬 정규화 결과를 직접 대조했다. 원본에서 한국어 설명이 있는 종 ID 집합과 수집 결과의 집합이 정확히 일치한다. 따라서 한국어 127종 결측은 수집기가 한국어 행을 버린 결과가 아니다.

127종은 모두 원본 설명 언어가 영어(`en`)뿐이다. 이름·분류명 테이블과 도감 설명 테이블은 별개이므로 한국어 이름이 1,025종 모두 있어도 한국어 설명이 모두 있다는 뜻은 아니다.

원본에서 `legends-arceus` 설명 241행, `scarlet` 120행, `violet` 120행은 영어로만 수록되어 있다. 8세대 후반·9세대의 해당 설명 번역이 이 스냅샷에 미수록되어 있다는 사실은 확인했다. 왜 기여·반영이 이루어지지 않았는지 개발진의 구체적 이유는 확인하지 않았으므로 일정·기술적 제약 등을 원인으로 단정하지 않는다. 이 결과는 원본 데이터의 수록 상태이며 게임 자체의 한국어 지원 여부를 나타내지 않는다.

참고로 공식 저장소 PR #1123의 '한국어 데이터 추가'는 `pokemon_species_names.csv`를 수정한 것으로, 도감 설명문 추가와 구별해야 한다.

- 원본 설명: https://github.com/PokeAPI/pokeapi/blob/2bf639e5572812a67d2b94903fdcb9d095f5aeb2/data/v2/csv/pokemon_species_flavor_text.csv
- 이름 변경 근거: https://github.com/PokeAPI/pokeapi/pull/1123

## 재현·출력·검증

```powershell
python scripts/analyze_pokemon_languages.py
```

- 원본 CSV 대조 결과, 세대/타입 집계 및 127종 목록은 로컬 `outputs/pokemon/language_audit.json`에 저장.
- 시각화는 로컬 `outputs/pokemon/missing-korean.html`에 생성. 대화용 생성 경로는 `--visual-path`로 지정할 수 있다.
- HTML의 `127종 목록`을 펼치면 도감 번호·이름·세대·타입·원본 언어를 볼 수 있다.
- 결과 HTML·목록·원본 데이터는 Git에서 제외. Git에는 분석 코드·데이터 없는 템플릿·이 집계 문서만 반영.
- 분석 실행: 전체 1,025 / 결측 127 / 원본과 정규화 한국어 집합 일치 / 결측 종 원본 언어 영어만 127 확인.
- 브라우저 검증: 736px와 360px에서 차트 2개·목록 127행 생성, 가로 넘침 없음, 목록 펼치기 동작, JavaScript 오류 없음 확인.

후속 서비스 설계에서는 한국어 설명의 존재 여부를 명시하고, 영어 근거를 이용한 한국어 답변과 원문 한국어 설명을 구분한다. 별도 번역문을 만들 경우 원문·버전·생성 번역 여부를 기록해야 하며 현재 번역문은 만들지 않았다.

후속 업데이트: 사용자 요청으로 생성 번역 보완을 완료했다. 위 분포는 원본의 결측 상태로 유지하며, 보완본의 결측 0종 결과와 구별한다. 절차·검증·파일 위치는 `TRANSLATION.md` 참고.
