# 포켓몬 테마 디자인 개편

2026-10-23. 사용자 요청으로 기존 Streamlit 앱을 포켓몬 백과에 맞게 개편한다. Figma OAuth 연결이 완료되지 않아 Product Design의 시안 탐색을 사용했다. 새로운 프론트엔드 심화 F2013이나 외부 배포를 구현한 것으로 세지 않는다.

## 현재 작업: 6a, 시안 탐색

기존 앱을 실제 실행하고 선택 포켓몬·대화·조건 탐색·진화 조건·지식 준비 건수를 확인했다. 현재 화면 캡처를 각 이미지 생성에 직접 첨부해 독립 시안 3개를 생성했다. 화면 시안은 실제 구현·모델 답변·데이터 검증 결과가 아니다. 시안의 예시 문구·버전·원문 출처·포켓몬 그림은 구현 시 실제 자료와 연결하고 검증해야 한다.

| 대화에서 표시한 순서 | 시안 방향 | 중심 화면 |
|---|---|---|
| 1 | 전자 도감 | 빨강/흰색 도감, 선택 포켓몬과 근거 대화 |
| 2 | 탐험 가이드 | 녹색/아이보리, 자연어 조건 탐색과 결과 선택 |
| 3 | 연구 노트 | 남색/종이색, 답변과 출처를 함께 읽기 |

선택 상태: **1번 전자 도감 + 2번 수채화 그림/조건 탐색**. 사용자의 조합을 반영한 합성 참조 시안을 생성한 뒤 기존 Streamlit 앱을 수정했다. Product Design의 시안 선택 후 구현 절차를 따른다. 시안 이미지와 캡처, 이미지 경로 매핑은 Git에서 제외한 로컬 outputs/pokemon/design/ 및 생성 이미지 보관소에만 남긴다. 이번 커밋은 작업 범위와 집계 기록만 포함한다.

## 선택 후 적용 범위

선택 시안을 기준으로 기존 앱의 색상·글꼴·간격·선택 패널·타입·입력/출처 표시를 개선한다. 기존 기능과 GMS 경로·항목 격리·실제 인용 출처·생성 번역 표기를 보존한다. 시안에 생긴 첨부·평가 버튼 등 미구현 기능을 그대로 노출하지 않는다. 캐릭터 이미지는 1,025종 모두의 그림을 확보했다고 가정하지 않는다.

최종 구현 후 기존 회귀 검사와 실제 화면 점검을 수행하고 최종 증빙을 새로 촬영한다. PDF 최종 판정·셀프/상호 체크리스트 점검은 별도 작업으로 유지하며 디자인 시안 생성으로 완료 처리하지 않는다.

## 이번 구현

전자 도감의 빨강/흰색, 타입 배지, 선택 포켓몬 프로필과 세 수치 요약, 근거 대화/빠른 조건 탐색 패널을 적용했다. 빠른 조건 입력은 실제 탐색으로 전환되어 전체 1,025종을 조건 검사하고 결과 선택 시 해당 종의 대화로 이동한다. 탐색 결과에는 2열 그림/수치/선택 버튼을 제공한다. 기존 버전·인용·세션·진화 카드 동작을 유지한다.

피카츄·코일의 수채화 에셋과 공통 실루엣 예외 동작, 다른 1,023종의 원본 이미지 연결을 제공한다. 다운로드 원본은 Git 제외다. src/pokemon/ui_theme.py에서 표시 문자열 이스케이프와 이미지 경로 범위를 검사하며 CSS는 별도 파일로 분리했다. 배경을 임의로 그린 가짜 캐릭터나 타 종 이미지를 실제 그림으로 표시하지 않는다.

개발 중 설치된 Streamlit에서 지원하지 않는 favicon 아이콘 이름을 발견해 실제 생성 PNG로 교체했다. UI 회귀 검사의 버튼 순번 의존도는 의미 있는 버튼 이름 선택으로 바꿨다. 기존 59개와 추가 표시/이미지 경로/빠른 탐색 4개를 합쳐 63개 테스트가 통과했다. 최종 브라우저 증거와 디자인 비교는 루트 design-qa.md를 따른다.
