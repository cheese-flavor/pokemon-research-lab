## 작성 기준

- 소개·현재 결과·탐색 경로는 루트, 장기 이력과 상세 재현은 하위 문서
- 기술 배지는 실제 패키지·코드·기록에서 확인된 도구만 사용
- 공식 점수·로컬 검증·계획·가상 시연을 구분
- 결과 수치는 대상·기간·비교 기준·한계와 함께 표기
- 읽기 쉬운 한국어 개조식·표·단순 Mermaid 흐름도 사용
- 과거 기록의 “현재·최고·미구현”은 해당 시점의 설명으로만 해석
- 기존 문서의 상세 검사 기록과 이번 링크·경로 검사를 구분
